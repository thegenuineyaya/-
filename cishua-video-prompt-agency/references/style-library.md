# Style Library

## Default Styles

`everyday-realism`: realistic home, school, street, office, shop, kitchen, gym, or outdoor scenes.

`clean-object-demo`: uncluttered object-centered scene for nouns and object features.

`physical-comedy`: safe exaggerated action for verbs, adverbs, surprise, and contrast.

`warm-learning-scene`: bright, friendly educational look with readable faces and subtitles.

`miniature-toy-scene`: small-scale stylized props for child-friendly memory anchors.

`documentary-closeup`: factual, quiet close-up for nature, materials, tools, or non-human subjects.

`contrast-demo`: side-by-side or before/after visual comparison for adjectives and degree words.

## Selection Notes

Prefer `everyday-realism` unless a stronger memory hook is needed.

Use `physical-comedy` only when the action remains safe and the word meaning benefits from surprise.

Use `miniature-toy-scene` for non-human characters only when it will not confuse the example sentence.

Avoid style labels in final prompts if the concrete scene description already communicates the style.
