# Director Toolbox

## Framing

- wide shot: use only when the setting or full-body action matters
- medium shot: default for people performing actions
- close-up: use for objects, facial reactions, hands, text, or key state changes
- over-the-shoulder: use for reading, choosing, comparing, or noticing

## Camera Motion

- static shot: use for clear teaching and object visibility
- slow push-in: use for discovery, realization, or important object detail
- gentle follow: use for continuous action
- quick pan: use for surprise, sudden movement, or fast contrast
- close-up insert: use to clarify object features or exact results

## Blocking

Place the subject and key prop in frame from the start when possible.

Use action lines that reveal cause and effect:

```text
subject sees problem -> subject acts -> visible result -> reaction or teaching cue
```

## Light

Use readable motivated light:

- morning window light for gentle, mild, warm, calm scenes
- bright classroom or desk light for learning and object demos
- shop or street light for everyday public scenes
- focused close-up light for small props

Avoid dark lighting unless darkness is the meaning.

## Performance

Describe visible performance:

- widened eyes
- relaxed shoulders
- quick hand movement
- careful inspection
- sudden pause
- relieved smile

Avoid invisible emotions without a physical cue.
